## Running Locally

Clone the repository:

```bash
git clone https://github.com/yourusername/w2-portfolio.git
```

Navigate into the project:

```bash
cd w2-portfolio
```

Open the project:

```bash
open index.html
```

Or simply open the main HTML file in your browser.
